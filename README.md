# Exp1_S2_lisbeth_bilbao

Actividad Formativa Semana 2 — Desarrollo Frontend II (PFY2202)

Sitio React de **Casa Gourmet** con:

- Navegación con React Router
- Estado global de inventario (Context + Provider + hook)
- Formulario para agregar artículos
- Tabla de consulta de inventario
- Estilos con Tailwind CSS 4

## Pantallas

- `/` — Inicio (incluye preview del inventario)
- `/quienes-somos` — Quiénes somos
- `/nuestras-tiendas` — Nuestras tiendas
- `/contactanos` — Contáctanos
- `/como-comprar` — Cómo comprar
- `/preguntas-frecuentes` — Preguntas frecuentes
- `/agregar-articulo` — Ingreso de artículos al inventario
- `/inventario` — Tabla con todos los artículos
- Cualquier otra ruta — Página 404

## Cómo ejecutar

```bash
npm install
npm run dev
```
